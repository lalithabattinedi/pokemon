Pokémon Dataset Visualization Project

This project explores the Pokémon dataset through a series of visualizations designed to uncover meaningful patterns and insights. Using Python libraries such as Pandas, Matplotlib, and Seaborn, the analysis focuses on understanding the distribution of Pokémon stats, type-based performance, correlations, and other key characteristics.

🔍 Key Insights & Visualizations

Stat Distributions: Visualized Attack, Defense, Speed, and other core stats to understand overall trends.

Type-Based Analysis: Compared average stats across primary Pokémon types to identify the strongest and weakest categories.

Correlation Heatmap: Explored relationships between different numerical attributes.

Generation Comparisons: Analyzed how Pokémon characteristics vary across different generations.

Combat Characteristics: Investigated which types have the highest attack values and which ones excel defensively.

🛠️ Technologies Used

Python

Pandas

Matplotlib

Seaborn

Jupyter Notebook

🎯 Purpose

The goal of this project is to practice exploratory data analysis (EDA) and create visually engaging charts that make it easier to understand how Pokémon differ in their stats, types, and strengths.
